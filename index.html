Field notes

What 10–100× actually means, and what it does not.

On the multiplier

10–100× is hours, not taste

The gain is recon, enum, evidence, first-pass reports, and parallel targets. Not the moment you decide which finding a real attacker would use. That call is still a pentester’s.

On agents, 2026

Kali is a UI for humans

Frontier models install their own tools, live in bash, and write bespoke Python exploits. Wrap tools when the human still needs a lever. Otherwise get out of the way and keep the judgment.

On MCP architecture

Wrap the tool, not the workflow

A good MCP server exposes tool functions, not opinions. Let the model decide when to run nmap versus CrackMapExec. The protocol is a bridge, not a script.

On isolation

Scope contamination kills credibility

Multi-client work requires hard isolation. No shared IPs, no shared tooling state, no ambient credentials. The infrastructure is the first thing you audit. Agents do not get a pass on that.

On loops

Do not prompt. Build a system that prompts itself.

A loop has a trigger, a verifiable end state, actions, a stop condition, and memory. Memory is what separates a loop that learns from one that spins. Single prompts are for demos.

On context

Agents are only as good as the tradecraft they retrieve

A chatbot can wing it. An agent with a shell cannot. The second brain exists so the model pulls my methodology when it decides the next command, not a generic playbook.
