Practice

How the work actually gets done.

Automate the mechanical

Reconnaissance, enumeration, evidence collection, initial reporting. AI handles the systematic work. Humans handle creative exploitation and business risk.

Intelligence, not checklists

A vulnerability scan is a map of where to look, not a report. The value is in deciding which finding a real attacker would actually use, and what it costs the business.

Build a loop that verifies

Think, act, observe, repeat until the goal is a file you can open. Repro steps, a patch someone can merge, a walkthrough an analyst can replay. If it does not lead to a fix, it did not happen.

Field notes

Lessons from 40+ assessments and a decade of notes.

On MCP architecture

Wrap the tool, not the workflow

A good MCP server exposes tool functions, not opinions. Let the model decide when to run nmap versus CrackMapExec. The protocol is a bridge, not a script.

On agents, 2026

Kali is a UI for humans

Frontier models install their own tools, live in bash, and write bespoke Python exploits. A lot of pentest MCPs are optional once the model can reach a shell. Wrap tools when the human still needs a lever. Otherwise get out of the way.

On cost

Model selection is a budget decision

Opus spent $200 on easy boxes. Sonnet is almost as good and 5x cheaper. Medium machines wander and eat tokens. Skip hash cracking in the agent loop: no skill, high spend.

On isolation

Scope contamination kills credibility

Multi-client work requires hard isolation. No shared IPs, no shared tooling state, no ambient credentials. The infrastructure is the first thing you audit.

On loops

Do not prompt. Build a system that prompts itself.

A loop has a trigger, a verifiable end state, actions, a stop condition, and memory. Memory is what separates a loop that learns from one that spins. Single prompts are for demos.

On context

Agents are only as good as what they can retrieve

A chatbot can wing it. An agent with a shell cannot. The second brain exists so the model pulls methodology, not folklore, when it decides the next command.
